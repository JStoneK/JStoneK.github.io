十三、推荐的日常工作习惯

对于自己的 GitHub 项目，建议遵循以下流程：

  1. 打开 VS Code，进入本地仓库。
  2. 执行 git pull origin main，同步远程最新版本。
  3. 修改代码、增加文件或调整文件夹。
  4. 执行 git add -A。
  5. 执行 git status，检查修改。
  6. 执行 git commit -m "本次修改说明"。
  7. 执行 git push origin main。
  8. 打开 GitHub 网页确认更新成功。

这四条命令基本覆盖了日常 GitHub 项目的同步与更新工作。
